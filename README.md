# Serial port Plotter 2.0 by Solderingironspb
Данная программа предназначена для отрисовки графиков, используя данные полученные по UART. Максимальное количество каналов - 8.
Программа имеет ядра опроса. В зависимости от выбранного ядра происходит опрос по заданному протоколу общения. 
#### В данный момент прописано 2 ядра: 
* Core_Embedded_ModbusRTU (ядро опроса по протоколу ModbusRTU. Адрес 0x01, функция опроса 0x03, адрес с 0 до 16 (8 переменных типа float)).
* Core_TPM101 (ядро опроса Овен ТРМ101 (ПИД-регулятор с универсальным входом в корпусе 48×48 мм). Опрос ведется по протоколу ОВЕН).
#### Программа значительно переработана. Ее можно использовать не как бездумную рисовалку графиков во время дебага, а как полноценный логгер с последующим анализом данных.

# Возможности:
* Вывод графиков в реалтайме. Во время вывода графика параллельно пишется бинарный файл.
* Возможность просматра записанных данных
* Преобразование записанных файлов в *.csv
* Сохранение скриншота графика из окна
* Ручное и автоматическое масштабирование
* Выбор: бегущий график или статическая картинка
* Динамическое расширение графика во времени по оси X
* Возможность скрывать ненужные элементы программы
* Возможность делать программу поверх всех окон
* Возможность убрать рамку программы
* Поддержка OpenGL(В зависимости от железа. На очень старых видеокартах может не работать)
* Программа сохраняет настройки окон, расположение окон и настройки подключения к COM порту
