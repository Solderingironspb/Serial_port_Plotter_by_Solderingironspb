# Serial port Plotter 2.0 by Solderingironspb
### Данная программа предназначена для построения графиков на основе данных, получаемых по UART. Поддерживается до 8 каналов одновременно. В основе работы программы лежат ядра опроса — в зависимости от выбранного ядра выполняется опрос устройства по соответствующему протоколу.

### На данный момент реализованы два ядра:

* Core_Embedded_ModbusRTU — ядро опроса по протоколу ModbusRTU. Параметры: адрес 0x01, функция 0x03, диапазон адресов от 0 до 16 (8 переменных типа float).
* Core_TPM101 — ядро опроса ПИД-регулятора Овен ТРМ101. Опрос выполняется по фирменному протоколу ОВЕН.

***Программа была существенно переработана: теперь она вышла за рамки простого инструмента для визуализации при отладке и представляет собой полноценный логгер с возможностью последующего анализа собранных данных.***

### Возможности программы:
* Вывод графиков в режиме реального времени с параллельной записью бинарного файла.
* Просмотр ранее сохранённых данных.
* Экспорт записанных файлов в формат *.csv.
* Сохранение скриншота текущего графика из окна программы.
* Ручное и автоматическое масштабирование осей.
* Выбор режима отображения: бегущий график (сдвиг по времени) или статическая картинка.
* Динамическое расширение временной шкалы по оси X по мере поступления данных.
* Возможность скрывать ненужные элементы интерфейса.
* Режим «поверх всех окон» для постоянного отображения поверх других приложений.
* Возможность отключения оконной рамки (безрамочный режим).
* Поддержка OpenGL (работает в зависимости от производительности видеокарты; на очень старом оборудовании может быть недоступна).
* Автоматическое сохранение настроек: расположение и размер окон, параметры подключения к COM-порту.
