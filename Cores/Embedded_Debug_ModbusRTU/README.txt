Ядро опроса для Embedded устройств.
Основная задача при создании устройства для работы с данной программой — разработать ModbusRTU slave-устройство со следующими параметрами:
Адрес: 0x01
Поддерживаемая функция: 0x03 (чтение holding registers)
Память устройства: 8 ячеек с переменными типа float.

Более подробная информация c примерами: https://github.com/Solderingironspb/examples_embedded_for_Serial_port_Plotter_by_Solderingironspb

Пример запуска ядра опроса из коммандной строки:
.\Core_Embedded_ModbusRTU.exe 10 115200 8 NOPARITY ONESTOPBIT 1000 4

Аргументы:
1: COM(1,2,3 и т.д.);
2: Bits per second (2400, 4800, 9600, 14400, 19200, 28800, 38800, 57600, 115200);
3: DataBits(7, 8);
4: Partity (NOPARITY, ODDPARITY, EVENPARITY);
5: Stop bits(ONESTOPBIT, TWOSTOPBITS);
6: Время между опросами (от 0 до 65535);
7: Количество каналов (от 1 до 8)

Вывод информации производится в отдельные буферы: sterr: информационные сообщения и ошибка, stdout: послезная информация

stdout выглядит следующим образом:
1 = 23.617188
2 = 0.000000
3 = 0.000000
4 = 0.000000
5 = 0.000000
6 = 0.000000
7 = 0.000000
8 = 0.000000
9 = 1783434036530

Вывод сделан именно таким, чтоб имелась совместимость с Serial port Plotter by Solderingironspb, начиная с версии 2.0

1 канал - Текущая температура
9 канал - Время, когда пришла информация в формате (Unix timestamp (миллисекунды))
